## Sobre o curso

Curso prático de Node.js focado na construção de uma biblioteca própria em JavaScript. Cobre leitura e escrita de arquivos com o módulo `fs`, lógica de processamento de texto, tratamento de erros, programação assíncrona (Promises e `async/await`) e uso do NPM para gerenciar dependências — culminando em um projeto final que integra todos os conceitos.

## Principais conceitos abordados

- **Arquivos**: leitura e escrita com o módulo nativo `fs`, caminhos absolutos vs. relativos.
- **Linha de comando**: captura de argumentos via `process.argv`, execução de scripts Node.js.
- **Lógica de processamento**: manipulação de arrays, strings e objetos aplicada a um problema real (processamento de texto).
- **Módulos**: organização do projeto com `import`/`export`, separando responsabilidades em funções e arquivos distintos.
- **Tratamento de erros**: `throw`, `try/catch`, o objeto `Error` e leitura de stack trace.
- **Programação assíncrona**: callbacks, Promises (estados pendente/resolvida/rejeitada), `then`, `async/await`.
- **NPM**: gerenciamento de pacotes, `package.json`, `node_modules`, instalação e uso de bibliotecas externas, versionamento semântico (SemVer).
